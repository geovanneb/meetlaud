# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful, assume good intent, and welcome people of every background and level of experience, in any of the project's four languages.

## Reporting

To report unacceptable behavior, email the maintainer at the address on their GitHub profile ([@geovanneb](https://github.com/geovanneb)), or use GitHub's "Report content" option on the comment or issue. Reports are kept confidential.
