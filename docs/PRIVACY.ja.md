# プライバシー

[English](PRIVACY.md) · 日本語 · [Português](PRIVACY.pt-BR.md) · [Español](PRIVACY.es.md)

2026年11月17日発効。このポリシーは、iPhone・iPad・Android 向けの Meetlaud アプリ（Google Play で開発者名 NovaAppsBR として公開している Android アプリを含む）に適用されます。

このページは、iPhone 版と Android 版のコードが実際に何をしているかをわかりやすく説明したものです。その多くはビルド時に強制されています(`ios/Tools/check-privacy` と `Tools/check-android`、許可リスト `ios/Tools/privacy-allowlist.json` と `android/privacy-allowlist.json` を参照)。この翻訳と[英語版](PRIVACY.md)に違いがある場合は、英語版が優先されます。

## 端末の外に出るもの

録音したもの、入力したもの、質問したものは、何も出ません。録音、文字起こし、話者の識別、要約、チャットはすべて端末の中で動きます。

アプリの通信は 2 種類です。2 つ目は任意で、設定するまではオフです。

1. **あなたが開始する AI モデルのダウンロード。** Hugging Face から、固定したバージョンとハッシュ検証つきで取得します。設定 > ネットワークアクティビティに、日時、接続先、サイズとともにすべて記録されます。この一覧は消去できます。消去後は「何も送信されていません」ではなく、履歴を消去したことが表示されます。

iPhone では、Apple Speech と検索のための言語モデルを iOS が自分でダウンロードする場合があります。これは iOS の動作であり、このアプリではなく、会議の内容も関係しません。Android にはこうしたモデルがないため、Android 版はほかのモデルと同じように検索用モデルを自分でダウンロードします。

2. **あなたがペアリングしたコネクタ。** Get Things Done と接続すると、新しい会議は、あなた自身のネットワーク上のそのコンピュータだけに、そのコンピュータ向けに暗号化されて届きます。標準では音声だけを送ります。文字起こしと写真はそれぞれ個別のスイッチで送れます。インターネットは経由せず、送信のたびにネットワークアクティビティに記録されます。

## アプリにないもの

アカウント、アナリティクス、クラッシュレポートサービス、広告、サーバーはありません。

## 端末に残るものと保存場所

| データ | 保存場所 | 端末のバックアップに含まれるか |
|---|---|---|
| 録音、文字起こし、要約、チャット、メモリ、声紋 | アプリ専用の領域 | いいえ(「ストレージとバックアップ」でオンにした場合を除く) |
| AI モデル | アプリ専用の領域 | 含まれません |
| 次の予定と最近の会議名 | アプリのウィジェットと共有するファイル | いいえ。「ウィジェットに会議名を表示」をオンにしたときだけ書き込まれ、オフにすると削除されます |

バックアップをオンにすると、録音は端末のバックアップ設定に従います。iPhone では iCloud、Android では Google のバックアップが含まれる場合があります。

## あなたが管理できること

- **アプリのロック:** Face ID、指紋、または画面ロックを求め、アプリスイッチャーでは内容を隠します。
- **ライブラリの書き出し:** パスワードで保護された 1 つのファイル(AES-256-GCM)。パスワードがなければ誰も開けず、復元もできません。声紋は、含めることを選ばない限り含まれません。
- **録音の削除:** 音声、文字起こし、要約、検索データ、その録音についてのチャット、それを引用した回答をすべて削除します。
- **すべて消去:** 上記すべてに加えて、モデルと設定も削除します。iPhone では、iOS 自身の言語モデルは iOS のものなので残ります。

## 声紋

声紋は生体情報です。任意で、人ごとにあなたの同意が必要で、「人物」からいつでも削除できます。

## 他の人を録音するとき

場所によっては、録音に相手の同意が必要です。これは利用者の責任であり、アプリは最初の録音の前にお知らせします。

## 正直にお伝えする限界

- AI は間違えることがあります。要約と回答には出典へのリンクがあるので、確認できます。
- 端末のロックを解除できる人は、アプリのロックをオンにしない限り、このアプリを開けます。

## モデルのダウンロードと Hugging Face

モデルのダウンロードは Hugging Face への通常のウェブリクエストです。そのため、一般的なウェブサイトと同じように、Hugging Face にはあなたの IP アドレスと要求したファイルが伝わります。アプリがそれ以外に送るものはありません。アカウントも識別子も、会議の内容も送りません。サーバーログの扱いには Hugging Face 自身のプライバシーポリシーが適用されます。

## Android の各権限の用途

| 権限 | 用途 |
|---|---|
| マイク | 録音のため。録音中のみ使います |
| 通知 | 録音の操作。オンにした場合は、リマインダーと文字起こし完了のお知らせ |
| カレンダー（読み取り） | 任意。今後の会議の表示と、録音への会議名の付与を端末内で行います |
| 生体認証 | 任意。アプリのロック |
| インターネットとネットワーク状態 | モデルのダウンロードと、ペアリングしたコンピュータ（上記） |
| フォアグラウンドサービス | 画面を消しても録音、文字起こし、ダウンロードを続けるため |

## データの保存期間

すべてのデータは、あなたが削除するまで端末に残ります。録音ごと、ゴミ箱ごと、または「すべて消去」でまとめて削除できます。アプリをアンインストールした場合も削除されます（オンにした端末のバックアップ内のコピーを除く）。ほかの誰もコピーを持っていないため、代わりに削除したり、復元したりすることもできません。

## お子さまについて

Meetlaud はお子さま向けではありません。また、そもそも何も収集しないため、誰からも意図して情報を収集することはありません。
